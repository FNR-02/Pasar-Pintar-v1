# Pasar Pintar Ecosystem
Platform digital yang menghubungkan pedagang, supplier, distributor, kurir, dan pelanggan dalam satu ekosistem perdagangan Indonesia.

## Cara Menjalankan:
1. Ekstrak file zip ini.
2. Jalankan `npm install` untuk menginstal dependencies.
3. Salin `.env.example` menjadi `.env` dan sesuaikan konfigurasinya.
4. Jalankan `npm run dev` atau `npm start`.
